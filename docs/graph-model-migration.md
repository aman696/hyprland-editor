# Reviewed saved-graph migration

Opening a supported older `.hye` workspace rebuilds its saved source graph in the current restricted workers and presents **Review rebuilt workspace**. Cancel is the default. **Use rebuilt copy** retains an in-memory draft; the existing unsaved-draft confirmation still applies. A draft change during either review discards the pending result. The rebuilt copy remains unsaved until the existing Save action writes a new private workspace. The selected old workspace is never overwritten.

This transition extends analysis beyond `hl.monitor` calls that previously stopped the evaluator. Monitor declarations still have zero modeled results; no compositor, assets or native rule manager runs. Fresh analysis must account for every captured view and resolution input, including previously unreachable saved inputs. A previously stopped graph that now needs an uncaptured dependency remains unresolved; no live folder access is inferred. A saved graph containing inconsistent or unreached inputs is refused. Saved bytes, private source pieces and typed draft values retain their original representation.

The reader accepts one selected regular `.hye` file, bounded to 8 MiB, with no final symlink following or FIFO/device I/O. Unknown saved payloads that the current decoder would discard are refused. After changing the candidate's model metadata, normal workspace validation and fresh restricted-worker replay verify compiler identity, captured views, source hashes, reached resolution inputs and private piece revisions. Materialized private edits are independently rebuilt and replayed. A fully removed loader request drops its binding from the materialized revision, with transitive unreachable bindings conservatively pruned; the saved original evidence is retained. Surviving request mutations still require renewed resolution input, and inserted code receives no captured resolution by textual resemblance. Original paths are historical evidence; migration never opens them or restores folder permissions. Lua is analyzed and compiled for syntax, never executed.

Reversing the candidate's model change must recover the entire decoded input exactly, including captured bytes, original identities, private pieces, typed drafts and resolution evidence. The summary binds the selected input and rebuilt workspace hashes, counts and unresolved analysis findings. A stopped or partial analysis remains partial; migration is not proof of effective compositor values or runtime behavior.

For a read-only check without GTK:

```sh
hyprland-editor --check-workspace-migration /absolute/path/old.hye
```

It reports the reviewed transition and reanalysis, writes nothing and requires exactly one argument. Ordinary `--check-workspace` continues to reject old graph models; it never silently migrates them.

Tests rebuild all ten supported models for both audited Hyprland snapshots with deleted original files and retained private source revisions. They refuse unknown models, foreign compiler profiles, source corruption, mismatched dependency requests, hidden payloads and unknown views. The native GUI workflow covers cancel, changed-draft refusal, protecting unsaved values, explicit replacement, a new private save and unchanged old-file bytes.

General older-model conversion, schema transformations, persistent operation history, full feature-family reconciliation and full source export remain required. This specific compatibility path does not certify those broader audit contracts.
