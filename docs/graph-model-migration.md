After changing the candidate's model metadata, normal workspace validation and fresh restricted-worker replay verify compiler identity, captured views, source hashes, reached resolution inputs and private piece revisions. Materialized private edits are independently rebuilt and replayed. A fully removed loader request drops its binding from the materialized revision, with transitive unreachable bindings conservatively pruned; the saved original evidence is retained. Surviving request mutations still require renewed resolution input, and inserted code receives no captured resolution by textual resemblance. Original paths are historical evidence; migration never opens them or restores folder permissions. Lua is analyzed and compiled for syntax, never executed.

The summary binds the selected input and rebuilt workspace hashes, counts and unresolved analysis findings. A stopped or partial analysis remains partial; migration is not proof of effective compositor values or runtime behavior.
