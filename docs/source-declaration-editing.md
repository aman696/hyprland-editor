# Edit captured declarations graphically

Open a retained project's **Ordered Calls**, select a device, binding, workspace rule, window/layer rule, curve, animation or gesture declaration, then choose **Edit / Compare This Declaration**. Open **Edit declaration fields…**, change the existing graphical controls, close that editor, and choose **Compare**. Review the proposed source patch and any additional findings before **Keep in Draft**. **Save Draft / Save Project As…** retains the source revision; the Files view can review/export the complete materialized file. Undo restores the previous project source.

The family form has an isolated temporary draft. Updating its fields does not change the project until Keep. It also does not change the separate whole-family drafts or the running desktop. Scalar and monitor declarations continue using their existing source editors.

Fields can come from a static declaration or captured modeled values, including module returns, local variables and computed expressions. A whole-declaration edit rebuilds arguments from that captured snapshot: computed links become explicit values. Shared variables and other source statements remain unchanged. Original comments within the replaced arguments are retained inside the new argument list; their exact spacing/placement is not preserved. The source review displays the replacement.

The restricted worker reconstructs source selection and arguments independently, validates the typed draft, serializes it with the existing family codec, reparses that output, and compares the complete captured graph. Callee spelling and surrounding source are preserved. Captured loader positions/hashes are rebased; other calls, loader inputs and enclosing submap contexts are compared. Input actions and imported Lua bytecode are never invoked. Parsed arguments do not prove native acceptance, hardware behavior or effective runtime state.

This operation edits one reached standalone declaration of the same API type. Keep one declaration in the temporary editor. General family insertion/removal, submap-container edits, sites reached repeatedly, consumed native objects, cycles and callbacks that cannot be represented by the existing graphical action codec remain unfinished or explicitly refused. No partial form silently drops unknown fields. The existing project still retains unsupported source.

Current evidence includes both audited snapshots and edits for devices, bindings, workspace/window/layer rules, curves, animations and gestures in captured modules. Additional cases cover computed values/shared variables, unchanged comments and surrounding source, nested submaps, later captured loaders, unchanged/type/count refusal and repeated/consumed source sites. The private graphical fixture uses the actual device form, comparison, Keep, undo and project persistence after original deletion. The existing full graphical fixture separately exercises every family editor.

The reconstruction model has 88 inputs and 22 exact reviewed predecessors. It adds this pure declaration editor and worker routing. Saved input formats/compiler profiles remain unchanged; all five preceding numeric-aware writers retain existing compiler observations. Migration reconstructs from retained bytes and restores no folder access.

Complete multi-file draft reconciliation and combined export/relocation, unrestricted dynamic source editing, full legacy structured editing, isolated compositor preview, live apply/recovery and all original release obligations remain required. This feature makes selected captured declarations editable with the existing graphical forms.
