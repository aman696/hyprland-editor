# Executed branch and loop evidence

Source analysis records the evaluated tests for `if`/`elseif`, `while`, `repeat`, integer numeric `for`, and short-circuit `and`/`or`. A decision identifies its immutable document/span/line, input-expression IDs, outcome and API/loader order. Numeric loops also record an empty/finished range and termination at an integer overflow boundary. Unknown tests still stop analysis; skipped branches and right operands do not acquire invented expressions or effects.

Expressions, storage writes, API observations and loader observations retain a `path_prefix` count into the report's append-only `path_decisions`. The prefix freezes the history available at that point. A repeat body precedes its first test; a call inside an `and` right operand follows the left-side decision; a module's decisions precede its later caller observations. Later tests cannot alter earlier snapshots.

This deliberately conservative history includes earlier unrelated decisions. It survives function returns and caught errors instead of dropping potentially relevant choices at a lexical block boundary. It is **not a minimal control-dependency slice**, a proof about skipped/future paths, or source-edit authority. Function selection, protected-call outcomes, callable escape/future callback effects, unsupported APIs, complete language coverage and exclusive literal/edit-impact ownership still need their own evidence. A write's prefix does not imply every possible write was modeled.

The graphical **Value sources** disclosure shows up to the last twelve decisions available at that particular observation, their source inputs and explicit omission notices. Existing shared node/depth/text limits apply. The full worker history is bounded to 8,192 decisions; input references share the 32,768 counted source-link budget and the 2 MiB serialized-report ceiling with expression/write evidence. Prefix counts avoid copying a growing list onto each expression or assignment. These logical limits are not a whole-process memory certificate; the [current empty-workspace measurements](resource-observations.md) do not certify the 100 MiB target for source-analysis workloads.

Tests cover false/elseif/else selection, Lua's truthy zero, skipped/evaluated short-circuit effects, body-versus-test ordering, range directions/empty ranges/integer limits, assignment prefixes, earlier-observation immutability, module boundaries, returns/caught errors, bounded growth and budget failure through `pcall`. The actual restricted-worker and private-display workflows check transport and graphical text respectively. The retained graph model pin changes with these inputs, so reopening rebuilds the evidence under the pinned model rather than trusting a stored analysis report.

The complete editable source workflow, live discovery, isolated compositor preview, guarded apply/independent recovery, resource/security gates and all original audit contracts remain unfinished.
