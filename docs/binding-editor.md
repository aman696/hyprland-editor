# Binding and submap draft editor — 0.7

Open **Menu → Edit Bindings**. This is a private draft editor: it never installs shortcuts, invokes dispatchers, grabs a seat or changes the running compositor. Choose a declaration and one of Shortcut, Options or Actions. Management controls and action preparation details are expandable so the ordinary editing view stays focused.

The constructor catalogue contains all 51 public `hl.dsp` constructors in the baseline and all 52 in the audited-main snapshot, with reviewed argument variants, version membership, effect descriptions and exact handler provenance. `reload_config` is current-only. `scripts/generate_actions.py --check` reproduces the action metadata and compares binding option names with both pinned handlers. Source inspection and our own codec round trips are not independent compositor behavior certificates.

| Area | Implemented draft behavior |
| --- | --- |
| Chords | Modifier switches, keysym choices, numeric XKB keycodes, mouse buttons, wheel direction, switch name/state, current-only sided modifiers and submap catchall |
| Recording | Explicit focused key-symbol recording; Escape cancellation, blur/unmap cleanup and a ten-second deadline; never global input capture |
| Options | All 13 baseline flags and the current-only mouse flag; descriptions/compatibility alias; include/exclude device-name or tag rows |
| Actions | Ordered constructor/variant controls, required/optional arguments, booleans/enums/numbers, type-preserving numeric selectors and literal text; zero to 64 actions |
| Submaps | Names, parent declaration scope, automatic transition, escape binding creation, subtree duplication and exact literal rename propagation |
| Relationships | Bounded static findings for exact duplicate declarations/options, shared names, undeclared transition targets and absence of a visible literal path to reset |
| Persistence | Schema-pinned private save/reopen, per-version dirty tracking, shared bounded inverse undo and combined Lua review |

Changes are staged into memory when Update Binding Draft is pressed, when switching declarations, before management operations other than explicit removal, before review/save and on a valid close. Action-row changes are retained when switching or reordering actions. An invalid current form blocks switching; closing offers an explicit choice to retain or discard that form. Removing a declaration intentionally discards its current form. Removing a submap with children is refused. Undo restores the prior staged draft and rebuilds its form.

Submap names are global upstream; parent nesting does not prefix a name. Renaming updates exact literal `hl.dsp.submap` arguments and reset destinations in this draft. Shared source/destination names make renaming ambiguous, so it is refused. Subtree duplication allocates fresh IDs/names and rebases its internal literal transitions while preserving external destinations. Neither operation rewrites opaque source code or external configuration. An escape binding is a draft transition to `reset`, not proof that input delivery or recovery will work on hardware.

Focused recording uses GDK key symbols and currently records Shift, Ctrl, Alt and Super/Meta modifier state. Other modifier combinations and physical XKB codes can be selected manually. It does not convert GDK event codes into compositor keycodes. Synthetic controller tests cover its state handling; physical layouts, shortcut interception and device routing remain unverified. The manual form retains an untouched imported chord's spelling, including aliases and leading zeroes, rather than normalizing it merely by opening the editor.

Baseline/current chord parsing differences are explicit: baseline modifiers require their source spellings, current rejects repeated case-insensitive tokens and supports sided modifiers, and current rejects keycode zero. The app uses the system libxkbcommon name lookup without opening a keymap or input device. Click/drag exclusivity, implied release conflicts, repeating/long-press conflicts and current mouse incompatibilities are checked before mutation.

Dispatcher preparation timing is preserved. A direct constructor or static local dispatcher was prepared during configuration loading; a constructor inside a binding callback is prepared when the callback runs. Export retains that distinction, including mixed action sequences through scoped local captures. The editor never constructs an upstream dispatcher or executes the exported Lua. Unknown callbacks, includes, dynamic control flow, query expressions, object handles and lifecycle logic stay unresolved; these need the future visual workflow engine.

Numbers retain finite values rather than being clamped to generic scalar bounds. Numeric selector values remain numeric, because upstream numeric-to-string conversion can differ from a literal string. Required values and optional false/zero/empty values stay distinct from unset. Selectors, layout messages, simulated shortcuts and commands still have literal input fields: complete versioned selector/message/shortcut builders and visual command/workflow composition are outstanding. This is not yet a complete code-free action editor.

`data/bindings.json` and `data/actions.json` jointly pin saved binding schemas. Older workspaces default to an empty binding graph; older applications reject nonempty new fields. Initial policies cap 10,000 binds, 128 submaps, 32 chord tokens, 64 actions per bind, 128 device targets and 4 MiB serialized graph data. The parser still limits one source to 1 MiB; the 10,000-record export fixture does not certify a maximum-size source reimport or acceptable memory use. Export indexes declarations by scope instead of performing pairwise scans. Undo retains changed records and necessary order inverses within the existing operation/data budget; persistent history remains open.

Static `hl.bind`, `hl.define_submap`, pure local constructors and parameterless literal callbacks containing `hl.dispatch` sequences are projected without Lua execution. Empty callbacks remain visible. Unknown evaluated arguments invalidate later load-time API trust; merely defining an opaque binding callback does not execute its body. Bind source-span editing, insertion/deletion, source reconciliation and legacy binding import remain unimplemented. Scalar source-copy export is blocked when it would omit binding edits; scalar comparison retains monitor/device/binding drafts unchanged.

Actual compositor parser/dispatcher conformance, effective bind-set resolution, device/tag intersections, lock/inhibit/capture delivery, source codecs, gestures, workflow nodes, safe live apply and isolated preview remain mandatory work. None of the full BIND contracts receives a release-wide certificate from this milestone.
