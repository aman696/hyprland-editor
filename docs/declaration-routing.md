# Declaration routing in captured projects

The Files / Ordered Calls inspector recognizes `hl.config`, `hl.monitor`, `hl.device`, `hl.bind`, `hl.workspace_rule`, `hl.window_rule`, `hl.layer_rule`, `hl.curve`, `hl.animation`, `hl.gesture` and `hl.define_submap` while following explicitly captured modules. Each call keeps its document, source span, ordered arguments and enclosing submap registration context. This removes the earlier stop at the first non-monitor structured family, allowing later captured modules to be inspected and retained.

This is bounded source analysis. It observes registration arguments; it does not certify native field acceptance or effective compositor state. Successful binding/rule handlers can return native objects. Consuming those objects or using their methods remains unresolved rather than inventing a return value or result count.

Known `hl.dsp` constructors preserve a typed, immutable snapshot of their construction arguments. The inspector labels them as uninvoked. Input-triggered binding and gesture callbacks remain inert. Direct dispatcher invocation is unsupported, and equality between separately constructed native closures remains unresolved. Constructor source arguments do not prove every native closure's runtime captures or side effects. Unsupported constructor forms remain explicit partial results.

`hl.define_submap` immediately invokes its registration callback in Hyprland. The restricted AST model follows that immediate callback, including nested submaps and captured module loads, and records completed/open scope intervals. It never executes imported Lua bytecode or input actions. Unmodeled operations, callback errors, recursion limits and missing captures stop analysis visibly. Source comparison checks enclosing scopes as well as retained argument/order/source correspondence, so moving a retained call between submaps is not accepted as an equivalent edit.

Existing worker, document, result, time and recursion limits apply. Dispatcher retention is bounded to 2,048 constructors and the existing aggregate payload budget; submap scopes are bounded to 256. Inspection adds no live IPC, file authority or idle polling.

Validation covers both audited snapshots, all declaration families, later and nested module loads, nested submap intervals, inert input callbacks, consumed-object/direct-dispatch refusal, callback errors/recursion, signed-zero constructor arguments, and source comparison across submap boundaries. These fixtures do not establish complete dynamic Lua, general native object methods or source ownership.

This increment enables inspection through those declarations; it does not complete those workflows.
