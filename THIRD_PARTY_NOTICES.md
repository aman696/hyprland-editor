# Third-party provenance

`data/scalars.json`, `data/monitors.json`, `data/devices.json`, `data/actions.json`, `data/bindings.json`, `data/workspaces.json`, `data/workspace-semantics.json`, `data/window-effects.json`, `data/layer-effects.json`, `data/rule-semantics.json` and `data/features.json` record source-derived setting names, types, literal bounds, default expressions, interfaces and factual audit results. Their source URLs point to exact Hyprland commits. No upstream implementation code is linked into the application. Documentation contains original audit/engineering analysis and links to upstream materials.

Hyprland is an independent project by its contributors, distributed under BSD-3-Clause; its wiki has its own licensing terms. This project is not affiliated with or endorsed by Hyprland. Source-derived default-expression fragments and interface names are retained only as metadata for interoperability. Upstream material remains subject to its original license; the MIT project license does not relicense upstream code or documentation.

Rust dependencies and GTK/libadwaita are independently licensed. The exact Rust dependency graph is recorded in Cargo.lock. Distributors must review and include the applicable dependency and platform notices for their package. No bundled system libraries or binary redistributions are shipped in this source repository.

The pinned Tree-sitter runtime (0.27.1) and Lua grammar (0.5.0) are MIT licensed dependencies; SHA-2 (0.10.9) is dual licensed MIT or Apache-2.0. Their sources are fetched by Cargo and not vendored into this repository. Cargo.lock records their integrity checksums and transitive dependencies.

The pinned quick-xml parser (0.38.4) is an MIT licensed dependency. Its checksum is recorded in Cargo.lock. Installed XKB registry choices are read locally on explicit request and are not redistributed; the repository includes only a small original synthetic XML fixture for tests. The keyboard registry parser does not resolve external DTDs/entities or compile a keymap.

The app links the system libxkbcommon for pure keysym-name validation; its stable `xkb_keysym_from_name` API is used with case-insensitive lookup. No keymap is compiled and no input device is opened by this lookup. libxkbcommon has its own license notices; distributors must retain the notices from their system library package.

The optional workspace source-conformance probe downloads reviewed, hash-pinned Hyprland functions into temporary test fixtures. Those functions retain their upstream BSD-3-Clause provenance and are not linked into the application or bundled in this repository. The fixture tests literal consolidation/default ordering using mock data, not compositor execution.

Rule sample checks link the system RE2 library through an original C++17 adapter. RE2 is BSD-3-Clause licensed; distributors must retain their system library package notices. Untrusted patterns are checked in the resource/syscall-restricted worker. The adapter is not copied from Hyprland; no Hyprland implementation is linked into the application.

The optional rule source probe downloads reviewed hash-pinned Hyprland functions into temporary fixtures and retains their BSD-3-Clause provenance. It compiles public Lua registration, effect accumulation and regex matching functions against real system Lua 5.4/RE2 and inert mock services. The fixture is not linked into the app; it does not certify upstream effect parsers, userdata, plugin APIs, window matching or compositor execution.

The ordered-module development worker links system Lua 5.4 through an original compilation-only C++ adapter. Lua is [MIT licensed](https://www.lua.org/copyright.html); distributors must retain their system package's copyright and license notices. No Lua library or upstream implementation is vendored here. `luaL_loadbufferx` is called in text-only mode without standard libraries or subsequent bytecode invocation. The independent ordered-module probe uses real Lua execution only for private trusted synthetic fixtures, plus hash-pinned upstream require/cache/searcher helpers in temporary directories. Those helpers are not linked into the application. Stored observations are interoperability facts, not a user-code execution, compositor, authorization or dependency ABI certificate.

The optional primitive rule-codec probe downloads SHA-256-pinned Hyprland and Hyprutils v0.14.2 sources to temporary fixtures. Their BSD-3-Clause provenance remains upstream; none is linked into the application. Stored parser observations are interoperability facts. The fixture uses real numeric/list/color parsing with inert graphics storage and a C++23 string-view concatenation compatibility wrapper. Complete upstream ABI/rendering behavior and all dependency profiles are not certified by these observations. See data/rule-codec-provenance.json and docs/rule-semantic-controls.md.
